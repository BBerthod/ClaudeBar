## D1 — `SettingsService` réécrit `settings.json` avec perte de données (S, valeur haute)
`SettingsService.saveSettings` (`Sources/ClaudeBar/Services/SettingsService.swift:40-46`) réencode `ClaudeSettings`, qui ne modélise qu'une partie des clés (`Sources/ClaudeBar/Models/ClaudeSettings.swift:64-90`). Chaque bascule dans Réglages › Claude Config (`SettingsClaudeConfigSection.swift:24,42,91`) supprime les clés inconnues du fichier de l'utilisateur. Correctif : fusionner dans le JSON brut, comme le fait déjà `UsageService.persistRefreshedToken`. Ajouter un test. Le README décrit `SettingsService` comme « Reads and watches », alors qu'il écrit.

## D2 — Le catalogue de modèles va bloquer la CI (S, valeur haute)
`ModelCatalogSnapshot.generatedAt = "2026-09-05T18:01:38Z"`. L'étape « Model catalog freshness » (`.github/workflows/build.yml:18-28`) échoue au-delà de 90 jours, soit à partir du **2026-12-04** : tout push ou toute PR sera rouge. Action : `make catalog` avant cette date. Option : un workflow planifié qui ouvre une PR de rafraîchissement.

## D3 — Blocage possible de la lecture Codex (S, valeur moyenne)
`ProviderUsageService.queryCodexDb` (`Sources/ClaudeBar/Services/ProviderUsageService.swift:171-186`) appelle `process.waitUntilExit()` **avant** `readDataToEndOfFile()`, sans délai maximal. La requête peut renvoyer 500 lignes de `feedback_log_body`. Au-delà du tampon du pipe (environ 64 Ko), `sqlite3` se bloque en écriture et la tâche attend indéfiniment. `GeminiActivityService.querySummaries` (`GeminiActivityService.swift:111-121`) fait déjà correctement l'inverse, avec un délai de 5 s : il suffit de reprendre ce modèle.

## D5 — Duplications (M, valeur moyenne)
1. **Lancement de `claude` dans Terminal via `osascript`** : `Views/Settings/SettingsQuickActionsSection.swift:151-191` et `Views/Analytics/AnalyticsSystemPanel.swift:393-411`. Script AppleScript quasi identique, seule la première variante gère iTerm2.
2. **Relance de l'app** : `AppDelegate.swift:130-146` et `Views/Settings/SettingsAppSection.swift:227-241`, identiques.
3. **Copie de `claude --resume <id>`** : `Views/Components/QuickResumeBar.swift:128-131` et `Views/SessionsView.swift:127-130`.
4. **Modèle du catalogue recopié dans le script** : `scripts/generate_model_catalog.swift:4` (« MIRROR OF Sources/ClaudeBar/Models — keep in sync »). La synchronisation est manuelle, avec un risque de divergence silencieuse. Pistes : une cible exécutable SPM qui dépend de `ClaudeBarLib`, ou un test qui compare les deux (effort L).
5. **Découverte des répertoires `~/.claude*`** : filtre `".claude" || hasPrefix(".claude-")` répété dans `SessionService.swift:94,107`, `Utilities/JSONLLocator.swift:11` et `Utilities/ClaudeDirectoryDetector.swift:28`.
6. **Appel `sqlite3` via `Process`** : `GeminiActivityService.swift:103-121` et `ProviderUsageService.swift:162-191`, avec des comportements divergents (voir D3). Un utilitaire commun corrigerait D3 du même coup.
7. **Formateurs de date** : 23 `DateFormatter()` ou `ISO8601DateFormatter()` sont instanciés dans `Sources/`, alors que `DateFormatter.isoDate` est partagé dans `Utilities/Extensions.swift:13`.
